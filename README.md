# Portfolio 2026

Umaru's portfolio site. Next.js (App Router, TypeScript) + GSAP.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Workflow

- Every change is one commit, with a message that says what changed and why.
- Versions that get published as a claude.ai artifact are tagged `v1`, `v2`, …
